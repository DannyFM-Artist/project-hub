# Product

## Register

product

## Users

One developer (Danny) running several software and show-tech projects in parallel, most of them driven through Claude Code and Claude Desktop sessions. The dashboard sits open on a second monitor or a browser tab during the working day. He glances at it between sessions to see where each project stands, and occasionally acts: moves an item, flips a phase status, posts a task to another project, clears the inbox.

## Product Purpose

project-hub is the single local source of truth for "where is every project, and what's next". Claude sessions write to it through the MCP server; Danny reads and adjusts it through the dashboard; any AI chat can recover full context from BIBLIA.md. Success: at a glance, without clicking, Danny knows each project's status, current phase, next step and whether anything is waiting for him; acting on it takes one click or one key.

## Brand Personality

Terse, exact, calm. A quiet instrument, like a show-control console trusted during a live event: it says only what matters, never decorates, never shouts. Confident without flourish; the data is the interface.

## Anti-references

- SaaS admin templates: generic card grids, hero metrics, gradient accents, sidebar plus avatar menu (the default Tailwind UI / shadcn look).
- Jira and enterprise PM tools: heavy forms, many fields, modal-driven workflows, bureaucratic feel.
- Notion-style soft docs: pastel, rounded, emoji-led, airy whitespace.

## Design Principles

1. Glanceable first: the overview answers "what's the state and what's next" without a click.
2. Every word earns its place: terse labels, plain verbs, no filler, no apologies.
3. One accent, colour means something: colour encodes status, type and attention, never decoration.
4. Keyboard and mouse are equals: every action has both, and shortcuts never surprise you while typing.
5. Calm under change: live updates never steal focus, wipe input or jump the layout.

## Accessibility & Inclusion

WCAG 2.2 AA: 4.5:1 text contrast, full keyboard use with visible focus, status never conveyed by colour alone, reduced motion respected, screen-reader announcements for action results and errors.
